# Разработка

Используйте **Go 1.25 или новее**, как требует `go.mod`. HTML, CSS и JavaScript встроены в бинарник панели; отдельная сборка фронтенда не нужна. Для импортёра конфигурации и проверки миграции требуется Python **3.11+**. Упаковка релиза также использует Bash и стандартные утилиты архивирования и проверки контрольных сумм.

## Компоненты

| Путь | Назначение |
| --- | --- |
| `cmd/panel`, `internal/panel` | Авторизация администратора, веб-страницы и обработчики запросов |
| `cmd/endpoint-agent`, `internal/endpoint` | Управление процессом TrustTunnel, применение настроек и откат |
| `internal/protocol` | Общие типы API панели и управляющего процесса |
| `deploy/` | Compose, Dockerfiles, nginx и Certbot hook |
| `scripts/` | Упаковка релиза, импорт настроек и проверки |

Панель обращается к управляющему процессу через Unix-сокет в общем volume. Процесс управляет своим дочерним TrustTunnel; Docker-сокет не передаётся ни в один из контейнеров. Настройки TOML и атомарно записываемое состояние JSON сохраняются в `runtime/`. Архитектура рассчитана на один сервер и одного администратора, отдельный сервер базы данных не нужен. См. [конфигурацию](./configuration.ru.md) и [эксплуатацию](./operations.ru.md).

## Проверки

Выполните из корня репозитория:

```sh
go test -race ./...
go vet ./...
python3 scripts/test-certbot-hook.py
```

Детектор гонок требует поддерживаемую платформу и C toolchain. Некоторые Go-тесты создают временные локальные Unix-сокеты. Тесты Certbot hook используют изолированные подставные команды и не обращаются к Docker или системным сервисам.

## Упаковка

```sh
VERSION=local GOARCH=amd64 ./scripts/package.sh
```

Для ARM-сервера укажите `GOARCH=arm64`. Архив в `dist/` содержит исходники и готовые Linux-бинарники; рядом создаётся контрольная сумма SHA-256. Настройки пользователей, `.env`, история Git и кеши в архив не входят. Перед сборкой Docker-образов распакуйте архив: Dockerfiles копируют бинарники из него. Перенос и развёртывание описаны в [установке](./installation.ru.md); при использовании архива Go и Git на сервере не нужны.

## Проверка миграции

`scripts/smoke-test.py` — серверная проверка миграции, а не обязательный шаг новой установки. Ей нужны Python 3.11+, curl, доступная исходная установка TrustTunnel с бинарником и ещё существующий файл `runtime/panel/bootstrap-password`. После смены пароля администратора этот файл удаляется.

Скрипт сравнивает экспортированные конфигурации клиента, проверяет страницы панели и QR-код, выполняет запрос через VPN с авторизацией и проверяет согласование HTTP/2 по TLS. Для HTTPS нужны `--panel-url` и действующий сертификат; аргументы доступны через `--help`. Даже обычный режим выполняет вход и передаёт тестовый VPN-трафик.

`--exercise-users` создаёт, применяет, отключает и удаляет временного VPN-пользователя, перезапуская endpoint в процессе проверки. Используйте его только на отдельном тестовом экземпляре. Этот режим запрещён с портом endpoint `443`, портом панели `8080` и HTTPS-адресами, но проверка не заменяет изоляцию тестовых данных и портов. После прерванного запуска проверьте пользователей и настройки тестового экземпляра перед продолжением.
