# TunnelaPanel

[English](README.md) · **Русский**

Веб-панель для управления собственным VPN-сервером [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel). Управляйте пользователями, выдавайте настройки подключения и следите за сервером через браузер.

Проект написан на Go и запускается через Docker Compose. Отдельная база данных не нужна. Интерфейс панели — на русском языке.

## Возможности

- Создание, редактирование, отключение и удаление VPN-пользователей; проверка изменений перед применением.
- Выдача клиентских настроек в виде TOML, ссылки подключения или QR-кода.
- Состояние сервера, подключения, счётчики трафика и журнал работы.
- Перезапуск TrustTunnel и перечитывание TLS-сертификатов.
- Вход администратора, смена пароля и журнал административных действий.
- Доступ через SSH-туннель или HTTPS на своём домене.

## С чего начать

Понадобятся Linux-сервер, Docker Compose, домен и TLS-сертификат. Проект можно собрать на сервере или перенести готовый архив с другого компьютера.

## Текущие рамки

Один сервер TrustTunnel и один администратор. Панель и управляющий процесс TrustTunnel работают в отдельных контейнерах; для HTTPS можно добавить nginx. Панель общается с управляющим процессом через Unix-сокет; Docker-сокет контейнерам не передаётся.

В готовой конфигурации закреплён TrustTunnel **1.1.0**, опубликован только TCP; QUIC/HTTP/3 не включён. Применение изменений пользователей кратковременно перезапускает VPN. Счётчики трафика сбрасываются при перезапуске TrustTunnel.
